# Metro

Metro is a canvas of linked cards kept as a [JSON Canvas](https://jsoncanvas.org) file. `@nyssance/metro` reads, writes and edits the document; `@nyssance/metro/canvas` shows it with shared gestures, and `snap`, `tidy` and `history` add alignment guides, automatic layout and undo.

How a canvas looks belongs to the application. Import `@nyssance/metro/presets/flow.css` for React Flow as it comes, `@nyssance/metro/presets/nyssance.css` for the Nyssance look, or your own stylesheet.
